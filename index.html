Imágenes y señales: de los píxeles a la predicción

Un modelo de Machine Learning nunca «ve» una foto ni «escucha» un sonido: recibe una matriz de números. Aquí aprenderás a prepararla, a extraer características útiles y a clasificar, con laboratorios que puedes manipular.

Competencia

Diseña e implementa un pipeline de visión computacional o de procesamiento de señales que transforme datos crudos en decisiones automáticas evaluadas con métricas adecuadas.

Objetivos de la sesión

Representar imágenes y señales como datos; aplicar filtros (convolución) y la FFT; extraer características; clasificar con k-NN; evaluar con matriz de confusión y comunicar el resultado al negocio.

Analogía de la plantilla

Un kernel es como una plantilla de cartón con agujeros que deslizas sobre una foto impresa. En cada posición sumas lo que ves a través de los agujeros (ponderado). Donde la foto «se parece» a la plantilla, la suma es grande. Una CNN hace exactamente eso, pero aprende qué plantillas usar.

Regla de oro: el modelo solo ve números. El trabajo del ingeniero es convertir la matriz cruda en un vector de características que separe bien las clases, sin filtrar información del conjunto de prueba.

    ¿Quién las diseña?El ingeniero (Sobel, HOG, FFT, RMS…)La red: los kernels de la CNN se ajustan con descenso de gradiente
    Datos necesariosCientos de ejemplos pueden bastarMiles o más (o transfer learning)
    InterpretabilidadAlta: «densidad de bordes = 0.40»Baja: requiere Grad-CAM, mapas de saliencia
    CómputoBajo: corre en un microcontroladorAlto: GPU para entrenar; edge con modelos ligeros
    Úsalo cuando…El entorno es controlado (luz fija, cámara fija) y hay pocos datosHay mucha variabilidad (fondos, poses, iluminación) y datos suficientes

    Histograma

    Distribución de intensidades. Resume brillo y contraste; base para umbralizar (Otsu).

    Bordes (Sobel, Canny)

    Cambios bruscos de intensidad = contornos. Densidad de bordes ≈ textura o grietas.

    HOG

    Histograma de orientaciones del gradiente por celdas (Dalal & Triggs, 2005). Clásico para detectar personas.

    LBP

    Local Binary Patterns: compara cada píxel con sus 8 vecinos → código de textura (Ojala et al., 2002).

    Estadísticos de señal

    Media, RMS (energía), pico, factor de cresta, curtosis (impactos).

    FFT por bandas

    Energía en rangos de frecuencia: una falla de rodamiento «suena» en una banda específica.

    Espectrograma / MFCC

    FFT en ventanas sucesivas → mapa tiempo-frecuencia. MFCC imita la percepción humana del sonido.

    Embeddings de CNN

    Vector de la penúltima capa de una red preentrenada (ResNet, EfficientNet). Excelente punto de partida.

    Matriz de confusión interactiva (clase positiva = «defecto»)

    Predice: DefectoPredice: OK
    Real: Defecto
    Real: OK
    Exactitud = (VP + VN) / Total
    Precisión = VP / (VP + FP)  ·  «de lo que alarmé, ¿cuánto era real?»
    Sensibilidad (recall) = VP / (VP + FN)  ·  «de los defectos reales, ¿cuántos atrapé?»
    F1 = 2 · P · R / (P + R)
    Trampa clásica: con 5% de defectos, un modelo que dice siempre «OK» tiene 95% de exactitud y 0% de sensibilidad. Prueba poniendo VP = 0, FN = 50, FP = 0, VN = 950.

    ¿Qué métrica elijo?

    Si dejar pasar un defecto es caro (salud, minería, aviación) → prioriza recall. Si cada falsa alarma detiene la línea → cuida la precisión. El costo de cada error lo define el negocio, no el algoritmo.

      4 · Del laboratorio al dataset real: dígitos manuscritos

      Dataset Optical Recognition of Handwritten Digits (UCI), incluido en scikit-learn como load_digits: 1 797 imágenes de 8 × 8 píxeles, intensidades de 0 a 16, 10 clases (0–9). Es el «hola mundo» de la visión computacional antes de MNIST (28 × 28, 70 000 imágenes).

      Una imagen del dataset (dígito 0) · pasa el cursor

      Cada celda es una característica. Aplanada, la imagen es un vector x ∈ ℝ⁶⁴.

      Pipeline mínimo en Python (scikit-learn)

      from sklearn.datasets import load_digits from sklearn.model_selection import train_test_split from sklearn.pipeline import make_pipeline from sklearn.preprocessing import StandardScaler from sklearn.neighbors import KNeighborsClassifier from sklearn.metrics import classification_report, confusion_matrix X, y = load_digits(return_X_y=True) # X: (1797, 64) y: (1797,) X_tr, X_te, y_tr, y_te = train_test_split( X, y, test_size=0.25, stratify=y, random_state=42) modelo = make_pipeline(StandardScaler(), # se ajusta SOLO con train KNeighborsClassifier(n_neighbors=3)) modelo.fit(X_tr, y_tr) y_pred = modelo.predict(X_te) print(classification_report(y_te, y_pred)) print(confusion_matrix(y_te, y_pred))
